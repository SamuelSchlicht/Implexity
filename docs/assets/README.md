# Figures and interface captures

The assets in this directory provide the geometric comparisons, the research figures, and the interface captures used by the repository README and the associated documentation. The static comparison figures include layouts for both wide and narrow displays, through which the panel arrangement is adapted to the available width while the underlying geometry is retained.

| Assets | Content |
| :--- | :--- |
| [geometry.png](geometry.png) and [geometry-mobile.png](geometry-mobile.png) | The prescribed variation of a periodic TPMS towards a branching cooled manifold, evaluated through the native Implexity geometry engine. |
| [geometry-morph.gif](geometry-morph.gif) | The animated sequence of the corresponding native geometry exports. |
| [scaffold-study.png](scaffold-study.png) and [scaffold-study-mobile.png](scaffold-study-mobile.png) | The unheated scaffold designs obtained under the loading conditions reported in the scaffold manuscript. |
| [scaffold-evolution.gif](scaffold-evolution.gif) | The sequence of the reported scaffold geometry panels. |
| [divertor-study.png](divertor-study.png) and [divertor-study-mobile.png](divertor-study-mobile.png) | The initial and final reported ageing-included divertor geometries, with the solid half-sections and the coolant volumes arranged in corresponding rows. |
| [gui-geometry.png](gui-geometry.png) and [gui-physics.png](gui-physics.png) | The unretouched workbench captures documenting the geometric definition and the physical add-in setup. |

The provenance and the scientific scope of the research panels are documented in the [research notes](../research.md). The model generation, the rendering, the manuscript extraction, and the layout reconstruction are described in the [reproduction guide](../frontpage/README.md), together with the corresponding source files and attribution.
